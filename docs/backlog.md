## 一、生成参数无法配置 ⭐ 当前最高优先

**问题：`/api/infer` 有 8 个参数，面板一个都没暴露。**

| 参数 | 默认 | 范围 | 面板状态 |
|---|---|---|---|
| `focal_factor` | 1.0 | > 0 | ❌ 未暴露（`infer.ts` 已支持传） |
| `max_points` | 400,000 | 1,000 ~ 5,000,000 | ❌ 未暴露（硬传 40 万） |
| `work_res` | 0（自动） | ≥ 0 | ❌ |
| `sample_mode` | structure | structure / depthpixel | ❌ |
| `edge_weight` | 6.0 | ≥ 0 | ❌ |
| `ink_weight` | 4.0 | ≥ 0 | ❌ |
| `edge_thresh` | 0（自动） | ≥ 0 | ❌ |
| `voxel_size` | 0（自动） | ≥ 0 | ❌ |

**要做的**：面板加「生成」分组（焦距 / 点数档位 / 重新生成按钮）。
**关键区别**：这些参数改动后需要**重新请求**（约 2 秒），不是即时生效 → 需要一个「重新生成」按钮。

**点数上限的约束**（实测）：`work_res` 自动值 = `clamp(原图长边/2, 512, 2048)`，
4000px 图 → 2000 → **候选 4M**。所以 `max_points` 到 400 万以内不需要改 Go；
超过 419 万需要提高 `work_res` 上限。

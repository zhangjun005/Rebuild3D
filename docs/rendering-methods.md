> **这份文档的用途**：把所有可尝试的点云渲染方式**先列全**，用统一编号 + 状态列跟踪实现进度。
> 目标不是"提高画质"，而是**探索多种渲染范式**，找出值得做成产品的几种。
>
> **规矩**：新增想法先加进清单（状态 ⬜），实现后改状态、补一行实验登记。
> 状态列是唯一事实来源，不要靠记忆。

## 1. 基元 / 笔触（L1 层）

每个点画成什么形状。**这一层变化最大、最便宜**（只改片元 shader，不动数据）。

| 编号 | 范式 | 一句话原理 | 观感关键词 | 需要的新数据 | 状态 |
|---|---|---|---|---|---|
| **A1** | 各向同性软圆盘 | `length(gl_PointCoord-0.5)` + smoothstep 软边 | 现在的彩色点画 | 无 | ✅ |
| **A2** | 硬边圆点 | 同上但不做软边 | 干净印刷网点 | 无 | ⬜ |
| **A3** | 方块 / 像素块 | `max(|x|,|y|) < 0.5` | 像素画、马赛克 | 无 | ⬜ |
| **A4** | 圆环 | 只画 `r ∈ [r0, 0.5]` | 粒子、线描感 | 无 | ⬜ |
| **A5** | 十字 / 加号 | 两条细矩形求并 | 制版对位印、十字绣 | 无 | ⬜ |
| **A6** | **短线段（带方向）** | 点画成沿切向的短线（世界或屏幕空间） | **笔触、排线、手绘** | 每点切向（从深度/结构图估） | ⬜ |
| **A7** | **椭球 splat（surfel/EWA）** | 按局部表面法线把圆盘拉成椭圆 | 表面连续、类 3DGS | 每点法线 | ⬜ |
| **A8** | 纹理 stamp（笔刷图章） | 用一张笔刷纹理代替解析形状 | 油画笔触、飞白 | 纹理资源 | ⬜ |
| **A9** | 三角形 splat | 每点一个随机朝向的小三角 | 纸屑拼贴、立体书 | 无（随机即可） | ⬜ |

> **A6/A7 是这一层最值得做的两个**：A6 决定"像不像手绘"，A7 决定"斜视时表面连不连续"。
> A2~A5 便宜，一次能全做，用来快速拉开观感差异。

## 2. 混合与叠加方式（L2 层）

点与点、点与背景怎么合成。

| 编号 | 范式 | 一句话原理 | 观感关键词 | 状态 |
|---|---|---|---|---|
| **B1** | 不透明覆盖（现在） | 深度测试 + 不透明写颜色 | 点画 | ✅ |
| **B2** | alpha 软叠加 | 关闭深度写、按 alpha 累积 | 水彩、雾 | 🟡（softness 只是软边，未真正累积） |
| **B3** | **加法发光** | `blending: Additive` | 星空、光晕、夜景 | ⬜ |
| **B4** | 只画轮廓不填充 | 片元只在环带写颜色，内部 discard | 点彩线描、镂空 | ⬜ |
| **B5** | 屏幕空间网点叠加 | 合成 pass 里叠网点（在屏幕坐标算） | 印刷半调 | ✅ |
| **B6** | 屏幕空间排线叠加 | 合成 pass 里叠排线 | 铜版画 | ✅ |
| **B7** | 深度自适应点径 | 按局部点密度调点径，刚好填满不重叠 | 无缝的表面 | ⬜ |

## 3. 颜色 / 色调映射（L3 层）

每个点用什么颜色。

| 编号 | 范式 | 一句话原理 | 观感关键词 | 控制参数 | 状态 |
|---|---|---|---|---|---|
| **C1** | 保留原色 | 每点带原图颜色 | 彩色点画 | `colorMode=1` | ✅ |
| **C2** | 亮度 → 点密度 | 暗处点多、亮处点少（单色墨） | 传统点彩 | `colorMode=0` + `stipple` + `densityGamma` | ✅ |
| **C3** | 暗度 → 墨量（结构加权） | 局部梯度大才上墨 | 线稿优先 | `inkSource` / `inkGain` / `inkPolarity` | ✅ |
| **C4** | 双色调（纸色↔墨色） | 两个颜色之间插值 | 丝网印 | `paper` / `ink` + `engraving`/`halftone` | ✅ |
| **C5** | 深度 → 墨量 | 按 z 决定墨量（强调层次） | 层次感 | `inkSource=2` | 🟡（与散落点耦合，效果不稳） |
| **C6** | **深度 → 色相** | 深度映射到色带（近暖远冷） | 深度可视化、地形图 | 无 | ⬜ |
| **C7** | **深度 → 点大小** | 近大远小（物理正确） | 空气透视、纵深 | 无（现有仅 1/z 投影缩放） | ⬜ |
| **C8** | 空气透视（颜色向纸色收敛） | 远的点颜色变淡 | 水墨远景 | `fogAmount` | ✅ |
| **C9** | 色调分离（posterize） | 颜色量化到 N 级 | 印刷品 | `colorPosterize` / `posterizeLevels` | ✅ |
| **C10** | 饱和度增益 | 提饱和 | 更艳 | `colorSaturation` | ✅ |

## 4. 世界空间图案（L4 层）

图案**贴在物体表面**而不是屏幕上——这是和 B5/B6 的本质区别。

| 编号 | 范式 | 一句话原理 | 观感关键词 | 状态 |
|---|---|---|---|---|
| **D1** | 屏幕空间网点/排线 | 图案固定在屏幕上，物体移动时图案不动 | 印刷 | ✅（B5/B6） |
| **D2** | **世界空间网点** | 图案随点贴在表面上，转动时图案跟着表面走 | 立体质感、真印刷 | ⬜ |
| **D3** | **深度等高线** | 按 z 分层画等值线 | 地形图、分层图 | ⬜ |
| **D4** | 表面法线光照 | 用每点法线做 N·L 明暗 | 立体、浮雕 | ⬜（依赖 A7 的法线） |
| **D5** | 环境光遮蔽（AO） | 按局部深度起伏算遮蔽 | 立体感、接触阴影 | ⬜ |

## 5. 合成后期（L5 层）

全屏后处理。

| 编号 | 范式 | 一句话原理 | 观感关键词 | 控制参数 | 状态 |
|---|---|---|---|---|---|
| **E1** | 边缘描边 | Sobel 深度边缘叠加 | 线描加粗 | `edgeStrength` / `edgeThreshold` / `edgeWidth` | ✅ |
| **E2** | 纸颗粒 | 叠噪声纹理 | 纸张 | `grain` | ✅ |
| **E3** | 暗角 | 径向变暗 | 聚焦主体 | `vignette` | ✅ |
| **E4** | 彩色网点叠加 | 屏幕网点只作用在颜色通道 | 印刷质感 | `colorHalftone` | ✅ |
| **E5** | **Bloom / 泛光** | 亮部模糊叠加 | 光晕、梦幻 | 无 | ⬜ |
| **E6** | **景深（DOF）** | 按深度模糊 | 摄影感、层次 | 无 | ⬜ |
| **E7** | 色调映射（ACES 等） | 高动态压缩 | 电影感 | 无 | ⬜ |
| **E8** | 色差 / 扫描线 / 故障 | 屏幕空间失真 | 复古 CRT | 无 | ⬜ |
| **E9** | 抖动（dither） | 有序抖动到有限色 | 复古印刷 | 无 | ⬜ |

## 7. 数据侧（每点属性 / 采样）

渲染范式能不能成立，往往取决于点云带了什么。

| 编号 | 范式 | 一句话原理 | 状态 | 备注 |
|---|---|---|---|---|
| **G1** | 结构感知采样 | 按图像梯度/墨量加权选点 | ✅ | `sampleMode=structure` |
| **G2** | 深度边缘剔除 | 剔 flying pixels | ✅ | `edgeThresh` |
| **G3** | 深度缝合压缩（IQR 判据） | 只压线稿处的层间伪影，不动真实台阶 | 🟡 | 代码在 `band.go`，**默认关闭待验证** |
| **G4** | 深度层量化（按连通域压平） | 整块压平 | 🟡 | **反例**：会丢角色立体感，默认关闭，仅作对照 |
| **G5** | 角色分割 | anime-seg 出角色 mask | 🟡 | 链路已通（sidecar `SEGMENT` + Go 客户端），**尚未用于渲染** |
| **G6** | **每点法线** | 从深度图算局部切平面 | ⬜ | A7/D4 的前置 |
| **G7** | **每点切向** | 从结构图算线条方向 | ⬜ | A6 的前置 |
| **G8** | 每点深度层 id | 分层归属 | ⬜ | F6 的前置 |
| **G9** | 点密度自适应 | 按局部密度调点径/抽稀 | ⬜ | B7 的前置 |

## 11. 验收标准（怎么算"这一项做完了"）

不满以下条件不要改状态：

| 层 | 验收条件 |
|---|---|
| A 基元 | 同一份点云能用参数切换；有对比截图；**不引入新 bug**（fps 与基线相比不劣化 > 30%） |
| B 混合 | 四种预设下都不炸（不出现纯黑/纯白/加法过曝）；有对比截图 |
| C 颜色 | 旋钮在面板上可调；HUD/meta 能回显实际值 |
| D 世界空间 | 转动时图案必须**跟着表面走**（这是和屏幕空间图案的唯一区别，要用两帧对比证明） |
| E 后期 | 可独立开关；关掉时像素级等于未加该 pass |
| F 运动 | 能用固定参数复现同一帧（供截图比对） |
| G 数据 | 新增属性要有 Go 单测；ILC1 若需扩展必须**向后兼容**（老文件仍能加载） |

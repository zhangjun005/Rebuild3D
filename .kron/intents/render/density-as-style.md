# 点密度是风格参数，不是质量指标

> 点数"越多越好"这个直觉在这条线上是错的。密度是表达明暗的美术量。

## 为什么（Why）

这是点云相对 mesh 的**唯一独特优势**：mesh 的采样密度由拓扑决定，无法自由调节；
点云的点数是一个可以随便动的量。

而"点画"（stippling）这门技法的本质，就是用点的疏密表达明暗——暗处密、亮处疏。
所以在这条线上，**降采样不是妥协，是创作手段**。

推论：UI 上不应出现"质量：高/中/低"，应出现"密度"这个美术滑杆。

## 如何（How）

三种实现，按"最正宗 → 最实时"排：

1. **预处理减少点数**——最正宗，但不可实时调
2. **每点透明度**——最简单，实时可调
3. **每点大小**——视觉上近似密度

## 权衡（Tradeoffs）

- 与"重建质量"的直觉直接冲突，需要文档和 UI 都明确标注这是美术参数
- 密度过低时描边会断、风格会碎，需要给一个下限

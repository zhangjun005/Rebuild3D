# 墨量跟随「结构」，不跟随「绝对亮度」

> > 修「主次颠倒」的核心。

这是端到端跑通后暴露的最严重的设计错误。

## 现象

真实插画上两种坏法：

| 输入 | 坏法 |
|---|---|
| 平涂（白裙角色） | **主次颠倒**：白裙（亮）几乎不上墨 → 变空白纸；粉背景（中调）被点铺满 → 抢戏 |
| 厚涂 | 主体碎裂成墨块 + 背景留白 |

## 根因

`墨量 ∝ 1 − 亮度` 这个映射，对**浅色主体**是错的：

- 白裙很亮 → 不上墨 → 主体消失
- 背景中调 → 大量上墨 → 背景变成视觉主体

**真实的版画 / 点画艺术家不会这么做。** 他们按「哪里有形体要描述」上墨——
褶皱、五官、纹理上墨，平坦区域留纸，跟那个区域本身是亮是暗关系不大。

## 做法：墨量映射三选

| 模式 | 规则 | 适用 |
|---|---|---|
| `按亮度` | `墨量 ∝ 1 − lum` | 深色主体（传统做法） |
| **`按局部结构`（默认）** | 用局部对比度 / 梯度幅值决定墨量 | **浅色主体、线稿密集** |
| `按深度` | 用深度分层决定 | 强调层间层次 |

再配一个**主体极性**开关：`自动 / 亮主体 / 暗主体`（自动按图像亮度分布判断）。

## 与采样的配合（重要）

Go 侧结构采样已经把「信息在哪」编进点密度了。**渲染层不应再用亮度二次抽稀把它逆转**：

```
Go  ：采样密度 ∝ 图像结构
Web ：忠实保留该密度，亮度只做轻微调制，不做主导
```

让「密度」从 Go 一路传达到屏幕，中间不被覆盖——这样点云才真的是信息载体。

## 教训

这条错误的可迁移形式：**"用绝对量做映射"在跨风格输入上必然翻车**。
凡是「按图像某个统计量映射到风格参数」的地方，都要先问一句「换一种画风它还成立吗」。

## 实测结果（2026-11-01）：**两层结论要分开说**

用 `scripts/analyze-depth.py` 直接分析 float32 原始数据（绕开会丢信息的可视化），7 张输入：

### ① 分层是可靠的，而且部分图不止两层

| 输入 | 主体vs背景分离度 | 三层聚类均值 | 三层占比 |
|---|---|---|---|
| 厚涂141118021（田野 2:1） | **0.885** | 0.61 / 2.79 / 5.05 | 47% / 23% / 30% |
| 平涂134481384 | **0.914** | 0.38 / 0.55 / 1.19 | 34% / 15% / 51% |
| 平涂131905131 | 0.764 | 0.40 / 0.69 / 1.17 | 41% / 16% / 43% |
| 真人照片 | 0.711 | 0.29 / 0.58 / 1.21 | 43% / 33% / 24% |
| 黑白漫画 | 0.554 | 0.68 / 0.86 / 0.98 | 15% / 42% / 43% |

**所以「2.5D 多层视差」是可做的**：把深度按阈值切成 3~5 层，各层以不同速率位移，
效果接近 Live2D / 3D Photo。

### ② 但主体内部确实几乎没有结构

`subject` = 最近 25% 像素，`sub_iqr_ratio = 主体内 IQR / 全局 p1-p99 幅宽`：

| 输入 | sub_iqr_ratio | 判断 |
|---|---|---|
| 厚涂141118021 | **0.0070** | 几乎零变化 = 一块板 |
| 平涂131905131 | 0.0431 | 接近板 |
| 平涂134481384 | 0.0567 | 接近板 |
| 真人照片 | 0.0643 | 有轻微结构 |

注：黑白漫画的 0.3061 不算"有结构"，那是网点噪声，不是几何。

## 结论

- ✅ **可以**：多层视差（2.5D）、点云风格渲染、小幅摆动
- ❌ **不可以**：自由环绕 360°（主体是板，转到侧面露馅）
- 相机限位 ±12~18° 这条仍然成立

## 校验时不要只看拼版图

拼版图有三处损失：1/99 分位裁剪、8 位量化、缩到 300px 高。
实测 8 位量化用满了 256 级（不是瓶颈），真正的损失是**缩放**。
要判"主体内有没有结构"，用 `scripts/analyze-depth.py` 的数值，不要靠肉眼。
